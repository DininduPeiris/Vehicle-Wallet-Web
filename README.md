# Vehicle Wallet website

A React and TypeScript landing site for the Vehicle Wallet mobile app. The privacy policy is available at `/privacy-policy`.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The site uses Vite and React Router. Configure production hosting to serve `index.html` for client-side routes such as `/privacy-policy`.
